**Download [TabbedNotepad.exe](https://github.com/Nerko69/tabbed-notepad/releases/download/v1.7.0/TabbedNotepad.exe)** below, put it anywhere and double-click it. No installation needed; runs on Windows 10 and 11. See the [user guide](https://github.com/Nerko69/tabbed-notepad/blob/main/docs/user-guide.md).

## New in 1.7
- **Smoother scrolling** in long notes (newer Windows text box; line numbers move together with the text).
- **Exact mouse selection:** selecting and Shift+click go to the letter gap nearest the mouse, no more jumping to whole words.
- **Background color** (Format → Background Color): soft colors and dark ones for the night, or any color.
- **Date/Time** (`10/16/2026-10:45 PM`, Shift+F5) and **Timestamp** (`10:45 PM 10/16/2026`, F5) buttons on the menu bar.
- **Picture previews:** hover over a link to a picture (pasted, on your PC, or on the web) to see it. Edit → Insert Picture Link.
- **Tab groups** are now off unless turned on (View → Group Tabs by Category), and grouped tabs share one color.
- Keyboard shortcuts open in a window you can copy from; Insert Date Line uses 99 dashes; dialog buttons fit their text at any display scaling.

## New in 1.6
- Separator lines (`#####`, `-----`) are no longer shaded, and highlights no longer turn dark.
- **Paste tables** from a web page, Excel or Word as lined-up text tables; **paste pictures** (saved as `.png` and linked).
- Small **category tags** on tabs (`CC2`, `WPP`, …).
- Renaming a tab opened from another folder renames its file too; Tools → Keep Old File When Renaming a Tab.

> Windows SmartScreen may warn the first time because the .exe isn't code-signed: click **More info → Run anyway**.
